# Computer Graphics and Animation

A collection of standalone browser-based experiments and visual studies exploring computer graphics, animation, and space-themed scenes.

## Contents

- **Lab Work** — computer graphics and animation exercises
- **My world** — just for fun

## Local Viewing

Open `index.html` in a browser, or serve the repository with any simple static web server. No build process or package installation is required.
